### Featured Projects

#### [BLIP Image Captioning](https://github.com/aqsa-05/BLIP_img_captioning_project)
*Generates natural-language captions for images using Salesforce's BLIP vision-language model.*
- Gradio web app for uploading an image and getting a caption, built on Hugging Face Transformers and PyTorch
- URL captioner that scrapes the images on a web page with Requests and BeautifulSoup and captions each one
- **Stack:** Python, PyTorch, Hugging Face Transformers, Gradio, Pillow, BeautifulSoup

#### [Emotion Detection Web App](https://github.com/aqsa-05/oaqjp-final-project-emb-ai)
*Flask app that analyzes text and returns emotion scores.*
- Returns scores for anger, disgust, fear, joy, and sadness, plus the dominant emotion
- Analysis logic kept in a separate Python package from the Flask server, with unit tests using `unittest`
- **Stack:** Python, Flask, NLP, unittest, HTML/CSS

#### [SecureVoteSphere](https://github.com/aqsa-05/SecureVoteSphere)
*A secure online voting platform with a zero-trust backend.*
- Node.js and Express backend with role-based route protection and audit trails
- Serverless PostgreSQL on Neon through Drizzle ORM, in-browser face authentication with face-api.js, and a WebSocket server for real-time admin alerts
- **Stack:** React, TypeScript, Node.js, Express, PostgreSQL, WebSockets

#### [RepoScope](https://github.com/aqsa-05/Reposcope) | [Live](https://reposcope-pi.vercel.app)
*Visualizes any public GitHub repository.*
- Interactive treemap, D3 force-directed graph, and file browser built from the GitHub API
- **Stack:** Next.js, React, TypeScript, D3.js, Framer Motion

#### [OneUni](https://github.com/abdull-ah-med/OneUniBackend) | [Live](https://oneuniversity.net)
*A university platform.*
- Built responsive frontend pages with Next.js, React, TypeScript, and Tailwind CSS
- Set up CI/CD with GitHub Actions and deployed the production API on Azure
- **Stack:** Next.js, React, PostgreSQL, Azure, GitHub Actions
